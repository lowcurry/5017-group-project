# 人工介入与决策成本

用同一批 Curve 3pool 历史调查判断比较六种策略。每个已生成的判断可直接采用、追加核验或交由人工。成本包括共享取数、模型生成、按需核验、人工时间、错误损失及适用的风险模型推理和训练摊销。

## 数据和口径

两个开发窗口合计 36 次预定研究判断，任务包括池内 USDC 占比方向、失衡峰值时点和集中度告警。同一事件及其所有重复运行共同留出。预测风险时只使用任务类型、报告引用数量和报告字段是否存在等当时可见的信息。逻辑回归和两种 CPU 神经网络方案都按此口径评估。神经网络先训练一个小型表格自编码器，再比较仅训练分类头和同时微调末个编码层。

成本计价使用可调整的情景参数。默认每次人工复核 5 分钟，每分钟 1 个成本单位，每次追加核验 0.2 个单位。人工复核后的残余错误概率默认 2%。币种余额、链上请求次数和模型用量来自归档。成本分析的人工计时栏待回收。全量核验相对原流程多 9 次转人工并拦下一次错误判断。按默认情景，避免这一错误的损失需超过 52.2 个成本单位（完美复核）或 67.7 个成本单位（计入残余错误）才划算。[情景参数](scenario.json) · [逐项结果](results/policy-trace.csv) · [盈亏临界点与风险分母](results/diagnostics.json)

## 结果与确认实验

成本规则和逻辑回归在历史回放中均有 2 次转人工、0 次自动错误，平均成本约 0.65 单位。两个末层训练方案各有 4 次转人工、0 次自动错误，成本约 1.18 单位。原始流程的 35 次自动判断只有 1 次错误，数据能支持历史策略比较和情景分析。高风险错误率的估计需要更多独立样本。

2023-06-15 的独立确认窗口已保存 Alchemy 和 dRPC 各 26 个小时目标（含追问时点），来源关键字段通过核对。用于确认实验的模型已冻结。九项参考的独立人工复核及 18 次正式模型运行待完成。

## 复现

按[仓库首页的目录布局](../README.md#离线复现)把基线包和成本包放在同一级，然后运行：

```sh
python3 -m pip install -r decision_cost/requirements.txt
python3 -B decision_cost/evaluation.py --output /tmp/5017-cost-replayed
```

可更改情景参数并用 `--scenario /path/to/scenario.json` 重跑。存在实测人工记录时，可以用 `--reviews /path/to/timing.csv` 载入，生成的空白模板在本地回放的输出目录。风险评分计时与其货币折算可随机器和负载变化。独立窗口的实测流程见下载包内的 `CONFIRMATION.md`。
