# 批量读数与预算优化验证

批量读取保留原始整数余额、报价、时点和区块标识。链上调用参数、已换算的数值等重复字段留在原始数据和核验链路里。工具结果进入模型上下文前，按同一客户端预算预检。回包超过剩余额度时，模型会收到可缩小读数范围、改用计算或提交现有结果的提示。
